# Project Images

Place your project images in this folder with these exact filenames:

- `flint.jpg`      → FLINT Edge AI Device photo
- `ezseva.jpg`     → EzSeva app screenshot
- `esp32car.jpg`   → ESP32 Obstacle Racing Car photo
- `rll.jpg`        → Real-Life Leveling app screenshot
- `sih.jpg`        → SIH 2026 prototype photo

After adding images, uncomment the Image component in `app/components/Projects.tsx`
(look for the comment `{/* Image goes here */}`).

Recommended size: 1200×800px minimum. Use JPG for photos, PNG for screenshots.
